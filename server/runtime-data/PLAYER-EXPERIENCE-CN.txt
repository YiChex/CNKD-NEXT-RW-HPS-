CNKD NEXT 玩家体验优化说明
============================================================

一、大厅同步降噪
------------------------------------------------------------

配置位置:
data/ServerConfig.json -> lobby

enableLobbySyncOptimization
- 默认 true。
- 开启后，服务端会过滤战役室内重复的 TEAM_LIST / SERVER_INFO 同步包。
- 目标是减少右侧频繁刷同步字段导致的客户端卡顿，尤其是大型模组房和锁图房。

lobbyRefreshHeartbeatMillis
- 默认 30000。
- 大厅状态没有变化时，至少每 30 秒仍刷新一次。该链路属于较重的大厅/队伍同步刷新，主要用于保护大型模组战役室体验。

lobbyPacketHeartbeatMillis
- 默认 30000。
- 同一个玩家收到的重复大厅包会被合并；到达心跳时间后仍会放行一次。

latencyHeartbeatMillis
- 默认 1000。
- 独立轻量延迟心跳，约每 1 秒刷新一次玩家延迟感知；只使用轻量 TEAM_LIST 更新延迟列，不触发 SERVER_INFO / SYNC 重刷。
- 心跳响应只更新服务端延迟采样，TEAM_LIST 延迟列由独立定时器统一刷新，避免多人同时回包时反复占用游戏主线程。

建议:
- 普通公开服保持默认即可；大厅同步保持 30 秒，延迟感知由独立 1 秒心跳承担。
- 如果你正在排查兼容性，可以临时把 enableLobbySyncOptimization 改为 false 对比效果。
- 不建议把大厅同步心跳调得低于 30000ms，否则会削弱大型模组降噪收益。

二、短线重连保护
------------------------------------------------------------

reconnectGraceMillis
- 默认 5000。
- 玩家短线后，服务端会等待 5 秒再触发正式离开事件。
- 如果玩家在保护窗口内重连，服务端会恢复其房间状态，并避免全服刷“进入/离开”消息。

优化目标:
- 降低移动网络、弱网、切后台导致的短线重连卡顿。
- 减少房主自动转移、公开列表刷新、自动开局重新计算造成的连锁抖动。

建议:
- 普通服保持 5000。
- 模组较大或海外网络玩家较多时，可以设置为 8000-12000。
- 如果你希望玩家断开后立刻完全离房，可设置为 0。

三、赛后回房与下一局衔接
------------------------------------------------------------

enableGameOverBattleRoomReturn
- 默认 false；配置缺失时也保持关闭。
- true：玩家看到“自动返回战役室”，服务端调用战役室返回链路，在线玩家可继续下一局。
- false：玩家看到“服务器强制重置”，服务端不会调用战役室返回链路，重置后需要重新进入。
- 两种模式使用不同提示，不再把强制重置描述成自动返回。

gameOverReturnCountdownSeconds
- 默认 30。
- 同时控制自动返回战役室和服务器强制重置前的等待秒数，范围 5-300。
- 建议保持 30 秒，让玩家看完结算并确认后续动作。

pruneDisconnectedPlayersOnGameOver
- 默认 true。
- 返回战役室前自动移除已经掉线但仍占用位置的玩家。
- 目标是避免下一局被幽灵玩家占位，并降低掉线玩家数据残留带来的卡顿。

四、后台观察命令
------------------------------------------------------------

startmode diagnose
- 会显示 sync.packetDropped、sync.refreshSkipped、reconnect.recovered、gameOver.return.triggered 等指标。
- 如果 packetDropped 持续增长，代表大厅重复同步包正在被成功合并。
- 如果 reconnect.recovered 增长，代表短线重连保护正在生效。
- 如果 gameOver.return.disconnectedPruned 增长，代表赛后掉线玩家清理正在生效。

config check
- 会检查大厅同步降噪、重连保护和赛后回房配置是否处于建议范围。

五、入房准备提示
------------------------------------------------------------

enableJoinReadinessTips
- 默认 false。
- 只有显式改为 true 时，玩家首次进入战役室才会收到当前地图、锁图状态、模组数量和自动开局条件。
- 短线重连恢复时不会重复发送，避免刷屏。

joinTipModWarningThreshold
- 默认 1。
- 当检测到的模组数量达到该值时，入房提示会提醒玩家客户端模组需要一致。
- 设置为 0 可关闭模组数量提醒。

六、玩家视角预期
------------------------------------------------------------

- 房主和后续玩家看到的锁图/队伍/位置状态应更一致。
- 战役室右侧同步刷屏频率应降低。
- 短线重连时不再频繁触发“玩家离开/玩家进入”的全服消息。
- 游戏结束后约 30 秒自动回到战役室，不需要重新进房即可继续下一局。
- 玩家进入房间后能快速知道当前地图、模组与自动开局条件。
- 进入游戏后的真实对局同步不被过滤，避免影响战斗过程。
