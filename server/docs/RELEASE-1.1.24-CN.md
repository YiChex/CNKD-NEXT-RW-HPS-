# CNKD NEXT 1.1.24 / Plugin API 1.3.0

本版本在1.1.23上增加可选赛后统计只读桥，配套独立`cnkd.match.analytics` 0.1.0采集插件与独立分析服务。无采集插件或开关关闭时不读取统计。原有S队、自由调位、地图锁独立语义与默认手动Start5秒保持。

## 宿主增量

- 在实际游戏线程复制六计数、四原生公式、模拟时间、颜色和个人结束观察；固定开局名单及协议身份摘要，昵称不做主键。
- 有界增量流、独立SESSION/TERMINAL、序号和持久ACK；游戏线程不执行插件自定义回调、文件、网络或数据库。
- 首次接受结算与清理前冻结终态，结束通知迟到不会读取下一局；停服/异常缺失明确标为中断或部分采集。
- API1.3.0增加read-statistics与默认PluginContext.statistics()扩展，旧1.2.0公共成员不破坏。宿主与插件API版本分开。
- 心跳任务初始化串行化，防止同时加入产生Quartz同名Job重复注册，附24并发回归。

## 配套安装

完整统计套件中`server/`包含宿主和采集插件，`analytics/`包含独立服务。旧实例升级先停服备份，替换JAR并保留现有data；新增插件后对实际全部插件重生成批准锁，保留EIRS条目。不要覆盖已有地图、模组、身份凭据或插件私有配置。

报告服务默认回环28480、管理员私有，整局结算并持久化后开放。玩家可选`.report`/`.战报`入口默认关闭，须配置独立采集应用凭据及自己的HTTPS报告地址。所有配置、安装和回退步骤见套件README。

宿主1.1.24不能独自提供统计网站；采集插件也不能加载到旧1.1.23 SDK上。回退时移除本插件对应批准项并切回保存的1.1.23 JAR，保留EIRS和统计journal/数据库/归档。

## 验收边界

原生回环对局、受控计数、持久回读、浏览器布局与合成百万点容量分别记录于套件VALIDATION-CN.md。原版PC/安卓同局逐点对照、完整玩法矩阵和真实两小时性能A/B仍须独立完成；不得以候选包构建通过替代生产验收。当前不自动部署生产。
